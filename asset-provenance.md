# Ассеты трёх блоков

Исходный файл `assets/natalia-original.webp` и `assets/webnat-logo.webp` сохранены без изменений. Фото не отправлялось на перерисовку лица: генератор подготовил только чёрно-белую маску силуэта для отображения исходного файла.

Встроенный генератор изображений использован для следующих файлов:

- `assets/sections-atmosphere.webp`: по полному утверждённому макету — чистый почти чёрный navy-фон, тонкие голубые/синие ленты по краям и реалистичные скалы снизу; тёмный пустой центр; без текста, карточек, людей, ноутбуков и логотипов.
- `assets/about-atmosphere.webp`: по присланному профилю — убрать человека и весь интерфейс; сохранить положение полного тонкого кольца (cyan слева, тёплый белый сверху справа, сине-фиолетовый снизу справа), тёмный фон и ленты по краям; никаких людей и надписей.
- `assets/portrait-mask.png`: по исходному фото — только чёрно-белая маска при исходной пропорции 760:1140 и неизменном положении силуэта; вся женщина и одежда белые, фон чёрный; никаких черт лица и текста, лёгкое сглаживание по краям волос.
- `assets/portfolio-house.webp`: по исходной маленькой миниатюре — реалистичный современный остеклённый дом в лесу в синий час, тёплый интерьер, прежняя композиция; убрать все надписи, метки, рамки и интерфейс; 16:9.
- `assets/portfolio-fitness.webp`: по исходной миниатюре — взрослая спортсменка в чёрном топе в профиль справа, тёмный зал с голубыми вертикальными огнями слева; убрать все надписи и интерфейс; 16:9.
- `assets/portfolio-headphones.webp`: по исходной миниатюре — чёрные полноразмерные наушники справа, голубой контровой свет, глянцевая navy-поверхность и фиолетово-голубые световые волны; убрать все надписи и интерфейс; 16:9.

Логотип 1С-Битрикс — официальный SVG с сайта 1c-bitrix.ru; `bitrix-mark.svg` показывает его исходный знак отдельным viewBox. WordPress — Simple Icons. Дополнительные интерфейсные иконки — Bootstrap Icons 1.11.3, без ручной перерисовки.
