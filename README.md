# WebNat — исправленный первый экран

Полная статическая версия действующего сайта. Откройте `index.html` или разместите содержимое этой папки на статическом хостинге.

Изменённые файлы: `index.html`, `styles.css` (убран предыдущий конфликтующий блок hero), `script.js` (только формулировка от первого лица). Добавлены `hero.css`, `hero.js`, фон сцены, локальные шрифты и готовые SVG-ассеты.

Логотип, фото и изображения портфолио сохранены побайтно. Нижние секции сохранены; в текстах этапов и контактов исправлено первое лицо. Форма, как раньше, копирует заявку и не отправляет её на сервер.

Четыре угла HTML-экрана задаются переменными `--screen-tl-x/y`, `--screen-tr-x/y`, `--screen-br-x/y`, `--screen-bl-x/y` в `hero.css`. `hero.js` автоматически пересчитывает перспективу при изменении размера.

Полный отчёт проверки — `design-qa.md`.

Обновлены три следующих блока: «Услуги», «Портфолио», «Обо мне». Их стили изолированы в `sections.css`. Отчёт — `three-blocks-qa.md`, происхождение ассетов — `asset-provenance.md`. Публикация GitHub Pages настроена на ветку `webnat-approved-hero-2026-11-06`.

Индексация сайта запрещена: meta robots/googlebot `noindex, nofollow, noarchive`, `robots.txt` с `Disallow: /`, а при размещении на Vercel — заголовок `X-Robots-Tag`. Файлы должны быть опубликованы на хостинге, чтобы запрет начал действовать. Это не парольная защита сайта и не настройка видимости репозитория GitHub.
